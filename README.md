# Karpo Travel Inc.

Your Journey, Our Priority.

Karpo Travel is a New York travel agency founded by Jenson Daniel. We arrange flights, hotels, vacations, cruises, cars, and visa assistance with a personal touch, backed by a family legacy in travel.

## Development

You need Node.js 20+ and npm.

```sh
npm i
npm run dev
```

Build and run the production server:

```sh
npm run build
npm start
```
